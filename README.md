## Overview

This repository provides ready-to-use Atmosphere builds with the necessary patches for **Tinfoil** to work properly on recent Nintendo Switch firmwares (21.0.0+).

It is based on the excellent [HATS](https://github.com/sthetix/HATS) project (Homebrew App Tools & Store) with only the Tinfoil compatibility patches applied. I am **not affiliated** with the original HATS project and take no credit for their work — this is simply a convenient full-pack distribution for users who prefer a plug-and-play solution.

## Features
- Latest Atmosphere versions with Tinfoil patches pre-applied
- Ready-to-install releases (no manual patching required)
- Regular updates following new Atmosphere and firmware releases
- Focused on stability and ease of use for the homebrew community

## Installation
1. Download the latest release from the [Releases](../../releases) section
2. Extract and copy the files to the root of your SD card (standard Atmosphere installation)
3. Boot using **fusee** or **Hekate**
4. Enjoy full Tinfoil functionality on Firmware 21+

## Known Issues
- Icon downloads may be broken since Firmware 21.0.0 (a common issue with Tinfoil on newer firmwares)
